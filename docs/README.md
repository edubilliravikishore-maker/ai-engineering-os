## Where to actually start

**Returning to the project?** [brain/Project-State.md](../brain/Project-State.md),
then [brain/Current-Focus.md](../brain/Current-Focus.md). They are maintained to be
read cold.

**Looking for a decision?** [brain/Decision-Index.md](../brain/Decision-Index.md)
indexes every ADR ruling in one line each.

**Implementing something?** The
[Implementation Blueprint](02-implementation/Implementation-Blueprint.md) is the
working specification — but where an ADR contradicts it, **the ADR wins**, and the
Blueprint carries inline markers saying so.

## Note on precedence

Design Sessions 001–009 froze the architecture and are unchanged. ADRs record
decisions made since, and supersede the Blueprint where they say they do. The
Blueprint is updated to match rather than left to drift.
